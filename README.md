# 乘法口诀小勇士 🧮

一个帮助记忆九九乘法口诀表的网页小游戏。

## 玩法

- 从「1 的乘法」打到「9 的乘法」，最后挑战混合模式；
- 每题从 4 个选项中选答案，答对得分并累积连击；
- **答错的题会自动排到队尾复现**，直到答对为止，实现"错题强化记忆"；
- 错题会进入本地错题本（localStorage），后续关卡会优先抽考；只有"首次答对"
  才算真正记住并从错题本移除，靠提示复现答对的题会继续留在错题本里；
- 每关结束按"首次答对率"结算 1~3 星，并提供错题口诀复习清单；
- 内置完整九九乘法口诀表，可随时查看。

## 运行

```bash
npm install
npm run dev
```

构建与预览：

```bash
npm run build
npm run preview
```

## 技术栈与结构

Phaser 3（画布背景/粒子）+ TypeScript + Vite，玩法 UI 全部使用 DOM 覆盖层，遵循
game-studio 的 2D 默认路径与"游戏状态与渲染分离"架构：

```text
src/
  game/
    simulation/   # 出题、会话状态、错题本（纯逻辑，唯一事实来源）
    content/      # 关卡配置
    assets/       # 稳定资源清单（当前为程序化视觉，无二进制资源）
  phaser/
    scenes/       # BootScene / MenuScene / GameScene（场景只做渲染）
    view/         # 漂浮符号背景等渲染辅助
    adapters/     # 场景与 UI 之间的事件桥
  ui/             # DOM 菜单 / 答题 / 结算 / 口诀表 / 音效
```
