# 乘法口诀小勇士 🧮

一个帮孩子把九九乘法口诀表**背下来**的网页小游戏。打开就考，答错的会再考一次。

## 玩法

- 打开主页，点「开始考试」直接进题，默认一轮 20 题（可在设置里改）。
- 出题范围由掌握度自动安排：先复习快要忘的，再推新口诀，保证进度一直往前走。
- **每道题都有倒计时**，剩余时间不足 30% 时会变色提醒；超时算"没答出来"。
- **答错或超时后不会自动跳到下一题**，会亮出正确口诀并停下，由孩子自己点
  「我记住了，继续」再往下走——看口诀的时间不该由计时器决定。
- **一轮的题数固定**：设置里选 20 题就是考 20 道，答错不追加、同题不在本轮重复出。
  答错的题会被记为"立刻该复习"，下一轮优先补考，所以仍会复习到。
- 题目随熟练度升级：新口诀用四选一 → 练习中改成自己算答案 → 已掌握后混入缺项填空
  （7 × ? = 56），必须真正想出来才能答。
- 只有**本轮第一次就答对**才推进掌握阶段。
- 结算页显示"一次就答对 / 本轮进步 / 最高连击"，并列出还要再练的口诀和超时题数。
- **错题本**（主页「📕 错题本」）随时可看：所有答错过的口诀都在这里，
  显示错了几次、最近错成了什么、什么时候错的，练会了也不会消失（标记为"已练会"）。
  如果错的答案正好是另一条共用因数的口诀的积，会提示"可能是把某条记混了"。
- 进度存在浏览器本地（localStorage），关掉再打开仍然保留；主页可「重新开始」清空。

## 错题本

主页的「📕 错题本」一次列出所有答错过的口诀，按"错得多的优先、其次最近错的"排序：

- 错了几次、最近一次错成了什么（超时则显示"超时没答出来"）、多久以前错的；
- 标记"还要练 / 已练会"——练会后的错题会保留但置灰，可以看出进步；
- 混淆提示只在**真正相关**时才给：错的数必须与原题共用至少一个因数
  （例如 6×7 答成 48，48 是 6×8 的积，共用因数 6，所以提示"可能是把「六八四十八」记混了"）。
  仅仅"积相等"的巧合不给提示，避免误导。

## 可调参数（主页 ⚙️ 设置）

- **每次练习题数**：默认 20，可选 10 / 20 / 30 / 45。
- **还没记牢的口诀 · 每题限时**：默认 15 秒（10 / 15 / 20 / 30）。
- **已经掌握的口诀 · 每题限时**：默认 8 秒（5 / 8 / 12 / 20）。
  背会的标准是脱口而出，所以这一档更快。
- 正在练习中的口诀取两个时间的中间值。

设置存在本地，改完立即生效，可一键恢复默认。

## 掌握度怎么算

45 条口诀（小九九，2×7 与 7×2 是同一条）每条独立记录阶段：

`还没掌握 → 刚学过 → 练习中 → 已掌握 → 很牢固`

- 答对一次推进一级（新口诀首次答对直接跳到"练习中"）。
- 答错一次退两级；**超时只退一级**（超时往往是犹豫、在推算，不是完全不知道），
  虚高的进度很快会被纠正回来。
- **已掌握要求连续两次答对**：第一题是四选一，存在猜对的可能，一步到位不够诚实。
- 到达"已掌握"后按间隔复习推进（半小时 → 一天 → 三天）。

主页的进度环、九行进度条和口诀表颜色，都是这套阶段的直接呈现。

## 装到别的电脑 / 手机上

这是一个纯前端网页，没有服务端，所以"安装"就是把网页放到一个对方能访问的地址上。
进度存在每台设备自己的浏览器里，互不影响。

### 方式一：同一个 WiFi 下直接玩（最快，不用任何账号）

```bash
npm run build
npm run share
```

会出现一个二维码和局域网地址，用手机的相机或微信扫码即可打开。

打开后按提示添加到主屏幕，就和普通 App 一样有图标：

- iPhone / iPad：Safari 里点底部分享按钮 → 「添加到主屏幕」
- Android：Chrome 里点右上角菜单 → 「安装应用」/「添加到主屏幕」

装好后**断网也能打开**（Service Worker 已缓存全部资源）。

注意：这种方式只在同一个 WiFi 下有效，电脑关机后手机就打不开了。

### 方式二：放到公网（任何设备、任何时间都能访问）

因为已经配好了 PWA（清单 + 图标 + 离线缓存），部署到任意静态托管都能被"安装"。
把 `dist/` 目录整个上传即可，常见选择：

- **Netlify / Vercel**：拖拽 `dist` 文件夹到网页上，秒出链接；
- **GitHub Pages**：把 `dist` 内容推到仓库的 Pages 分支
  （`vite.config.ts` 已设 `base: "./"`，子路径也能正常工作）；
- **自家服务器**：把 `dist` 放到 Nginx 的静态目录。

⚠️ 想让手机能"安装"（出现图标、独立窗口、离线可用），地址必须是 **HTTPS**
（或 localhost）。上面几种托管都自带 HTTPS，直接可用。

部署后如果更新了代码，重新 `npm run build` 并覆盖上传即可，
已安装的设备下次打开会自动更新。

## 技术栈与结构

Phaser 3（画布背景/粒子）+ TypeScript + Vite。玩法 UI 全部是 DOM 覆盖层，
遵循 game-studio 的 2D 默认路径与"游戏状态与渲染分离"架构：

```text
src/
  game/
    content/facts.ts          # 45 条口诀内容（唯一内容来源）+ 行元数据
    simulation/
      mastery.ts              # 每条口诀的掌握阶段与间隔复习（唯一事实来源）
      planner.ts              # 智能抽题：到期复习 → 练习中 → 新口诀 → 薄弱补足
      questions.ts            # 三种题型生成（四选一 / 自己写答案 / 缺项填空）
      session.ts              # 一轮练习的会话状态、错题复现
      daily.ts                # 每日目标与连续学习天数
  phaser/
    scenes/                   # BootScene / MenuScene / GameScene（只做渲染与特效）
    view/                     # 漂浮符号背景
    adapters/                 # 场景与 UI 之间的事件桥
  ui/
    app.ts                    # 主控制器：编排界面、转发输入
    screens/                  # home / quiz / results / chart 四个界面
    sound.ts                  # WebAudio 合成音效
```

注：PWA 离线缓存只在生产构建下启用，开发环境会自动注销 Service Worker
并清理缓存，避免改动被旧缓存挡住。
